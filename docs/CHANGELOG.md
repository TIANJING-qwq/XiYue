# 更新日志

汐月（XiYue）的版本变更历史。

格式参考 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)，版本号遵循 [语义化版本](https://semver.org/lang/zh-CN/)。

> 变更内容依据 Git 提交记录与版本标签整理。早期版本（`dev0.1` ~ `v0.3.2`）的提交说明较为简略，此处按功能域做了归类。

## [未发布]

### 新增
- **更改设置需要安全码**：开启后，每次进入设置页都需先输入安全码，验证通过后本次可自由修改
  - 设置页新增开关，位置在「退出安全码」下方
  - 仅在「退出安全码」已开启且安全码非空时生效
  - 离开设置页或重启程序后重新上锁
  - 未设置安全码时开启该选项会被回退并提示

### 变更
- **安全码自身受保护**：关闭「退出时验证安全码」、或修改/清除安全码，都必须先验证当前安全码
- `QuitPasswordDialog` 改造为通用安全码验证对话框（标题 / 提示 / 按钮文字 / 错误文案可自定义），退出场景的默认行为与文案不变
- 配置新增 `ProtectSettingsEnabled`（默认 `false`，旧配置自动兼容）

## [0.3.9] - 2026-10-01

### 新增
- **插件系统**：支持动态加载第三方 .NET 8 类库插件
  - 插件契约 `IXiYuePlugin`、上下文 `IPluginContext`
  - 加载器 `PluginManager`，每个插件独立数据目录与配置文件
  - 内置插件管理页 `Views/PluginsView.axaml`
  - 配套文档 `docs/PLUGIN_DEVELOPMENT.md`
- **涩图合集（图库）**：图片资源不打包进程序，按需从 GitHub Release 下载
  - 支持 JPG / PNG / GIF / BMP / WebP / ICO，GIF 自动播放
  - 网格缩略图 + 独立大图预览窗口，本地缓存

### 变更
- 开源许可证变更为 **BSD-3**

### 修复
- 修复窗口材质（云母 / 亚克力）异常
- 修复点击音效播放问题
